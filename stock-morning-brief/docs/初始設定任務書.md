# 初始設定任務書（給 AI 讀的安裝訪談腳本）

> 你是一個 AI 助理，使用者剛 clone 了 stock-morning-brief 這個專案。
> 你的任務：**逐題訪談使用者 → 產生 config.yaml 與 .env → 實測推播 → 建立每日排程**。
> 原則：一次只問一題、用使用者的語言、選項給預設值、不要求使用者懂程式。

## 第 0 步：環境檢查

先默默確認（不用問使用者）：

```bash
python --version        # 需要 3.10+
pip install -r requirements.txt
```

裝不起來再回報並協助排除。

## 第 1 步：訪談（一次一題）

### Q1 市場
「你想看**台股**、**美股**，還是**兩個都要**？」
→ config `market: tw / us / both`

### Q2 要不要「AI 市場重點」段
「晨報可以多一段 **AI 網搜的市場重點**（5~8 條，每條附來源連結）。
要的話需要你電腦上有一個會網搜的 AI CLI（例如 Claude Code）並且已登入；
不要的話，晨報就是「健檢箭頭＋K線圖」，一樣每天準時送達。」

→ config `ai.enabled: true / false`
- 選要 → 確認 CLI 指令跑得動（`claude --version`），把指令或完整路徑寫進 `ai.cli`
- CLI 沒登入 → 提醒使用者在終端機登入一次（例如 `claude login`），這是一次性動作
- 選不要 → 跳過 Q3，直接問 Q4

### Q3 新聞來源（⚠️ 一定要主動把預設清單攤開給使用者看）

先照 Q1 的市場，把**預設會用的來源列出來**給使用者過目，再問要不要增補。
不要只問「你要哪些來源」——使用者通常答不出來，看到清單才有感覺。

範例講法：

> 「市場重點我預設只會從這些來源找新聞：
>
> **台股**：鉅亨網、聯合新聞網／經濟日報、Yahoo 股市、ETtoday 財經、MoneyDJ
> **美股／國際**：Yahoo Finance、路透 Reuters、CNBC
> **一手來源**（永遠允許）：央行與主管機關官網、交易所、上市公司官方新聞室
>
> 為什麼要限制：不限制的話，AI 會搜到個人部落格、內容農場、新聞聚合站，
> 甚至工具型網站，內容品質參差會影響你的判讀。
>
> **你有沒有特別信任、想加進來的網站？**（例如你常看的券商研究、產業媒體、
> 特定財經節目網站）也可以直接說『就用預設的』。」

→ config `ai.sources`
- 使用者說要加 → 附加到清單（幫他把網址整理成網域格式，如 `example.com`）
- 使用者說某個預設來源他不看／不信任 → 從清單移除
- 使用者說「都可以、不用限制」 → 設成 `sources: []`（不限制），但要提醒一句：
  不限制的話來源品質會參差，之後隨時可以在 `config.yaml` 加回來

### Q4 自選股
「想追蹤哪幾檔股票？告訴我代號或名稱就好（例：2330 台積電、AAPL）。」
- 台股代號自動補 `.TW`；名稱不確定時幫使用者查代號後複述確認
→ config `watchlist`

### Q5 技術指標
「圖上想看哪些技術分析？
1. K線＋MACD（預設，適合看趨勢轉折）
2. K線＋MACD＋均線（MA5/20/60）
3. 只要 K線」
→ config `indicators: [kline, macd] / [kline, macd, ma] / [kline]`

### Q6 通知時間
「每天幾點推播給你？（台股開盤 09:00，建議 08:00；美股為主可選收盤後的早上）」
→ config `notify_time`
- 小提醒：整點是所有人排程的尖峰，幫使用者錯開幾分鐘（例如 08:07）比較不會塞車
- 若啟用了 AI 市場重點與查核，整份流程約需 3~8 分鐘，排程時間要把這段算進去

### Q7 儲存位置
「每天的報告和圖檔要存哪？
1. **本機資料夾**（預設、推薦）：存在專案的 archive/ 裡
2. **不存檔**：只推 Telegram，看完即丟
3. **Google Drive**（進階）：另外備份上雲端，需要安裝 gws CLI 並走 Google 授權，會多花 10 分鐘」
→ config `storage: local / none / gdrive`
- 選 gdrive 才引導安裝 gws（`npm i -g @gws-cli/gws` 後 `gws auth`），並要求提供雲端資料夾 ID 填入 `gdrive_folder_id`

### Q8 Telegram
「最後一步，建立你自己的 Telegram 機器人（約 3 分鐘）：
1. 在 Telegram 搜尋 **@BotFather** → 傳 `/newbot` → 取名字
2. BotFather 會給你一串 token（`123456:ABC...`），貼給我
3. 對你的新 bot 傳一句 hi」

拿到 token 後：
- 複製 `.env.example` 為 `.env`，填入 token
- 呼叫 `https://api.telegram.org/bot<token>/getUpdates` 取得 chat_id，填入 `.env`
- ⚠️ token 是機密：不要顯示在對話紀錄以外的地方，確認 `.env` 已在 `.gitignore`

## 第 2 步：產生設定並實測

1. 依訪談結果寫 `config.yaml`（參考 `config.example.yaml` 的欄位）
2. `python notify.py --text "設定完成測試 ✅"` → 使用者手機收到才算過
3. `python brief.py --no-push` → 確認 archive/ 產出圖、健檢表與簡報；
   有啟用 AI 的話順便確認「市場重點」段真的有內容（沒有的話多半是 CLI 沒登入）
4. `python brief.py` → 完整跑一次，確認 Telegram 收到文字＋圖片

## 第 3 步：建立每日排程

排程直接叫 `brief.py` 一支就好（它會自己依序跑完畫圖、AI、推播）：

- **Windows**：
  ```powershell
  powershell -ExecutionPolicy Bypass -File install_schedule.ps1
  ```
  會讀 config 的 `notify_time` 自動建立工作排程器任務，用 `pythonw.exe` 執行
  （完全不跳視窗）。

- **macOS / Linux**：crontab
  ```
  7 8 * * * cd /path/to/stock-morning-brief && /usr/bin/python3 brief.py >> cron.log 2>&1
  ```

⚠️ **不要**把整份流程設成「AI 對話式排程」（例如 AI 工具內建的排程任務）：
那會每天開一個新對話把對話列表灌爆，遇到未授權指令還會跳權限詢問等人按允許，
沒人按就整份卡死。讓系統排程器跑 `brief.py`，AI 只在需要判斷力的那一段被呼叫。

## 第 4 步：收尾

- 跟使用者複述最終設定（市場／AI 開關／來源清單／幾檔自選股／指標／時間／儲存方式）
- 告知以後怎麼改：直接編輯 `config.yaml`，或再叫 AI 讀這份任務書重跑訪談
- 告知除錯看哪：`last_run.log`（上一次執行的完整輸出）、`run_history.log`（歷史累積）
