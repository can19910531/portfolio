# 每日晨報任務書（給 AI 排程讀的執行腳本）

> 這是給「會網搜的 AI agent」讀的每日任務。純腳本排程（charts.py＋notify.py）只有圖表＋健檢；
> 讓 AI 跑這份任務書，可以多拿到「市場重點」新聞段。
> ⚠️ 本簡報是資訊彙整，不是投資建議；永遠不做任何下單／交易動作。

## 流程

### 1. 跑腳本產圖＋健檢
```bash
python charts.py
```
產出在 `config.yaml` 的 `archive_dir` 下：`YYYY-MM-DD_圖/` 與 `YYYY-MM-DD_健檢.md`。

### 2. 網搜市場重點
**規則**：只取 24 小時內新聞（週末可放寬到 72 小時）；每則必附來源連結；查不到就寫「查無」；禁止憑空編造數字。

範圍（濃縮成 5~8 條 bullet）：
- 大盤動態一句話（依 config 的 market 決定台股/美股/兩者）
- 現在市場的熱門趨勢／題材（資金流向、討論熱點）
- 影響今天開盤的 1~2 個關鍵變數

### 3. 組簡報（固定模板）

```markdown
# 📈 股票晨報 YYYY-MM-DD（週X）

## 🔥 市場重點
- {重點，一句話}｜[來源](url)
- …（5~8 條）

## 🩺 自選股健檢
{直接貼入 charts.py 產的 YYYY-MM-DD_健檢.md 全文——箭頭由程式算，AI 不要自己判}

（K線圖隨後送達 📊）

---
📌 本簡報為 AI 自動彙整之公開資訊，僅供參考，**非投資建議**。
```

休市日改成「本週回顧＋下週展望」，標題加「（假日版）」。

### 4. 歸檔與推播（順序固定：文字先、圖後）
1. 簡報存 `<archive_dir>/YYYY-MM-DD_晨報.md`（storage 為 none 就跳過）
2. storage 為 gdrive 時：`gws drive +upload "<檔案>" --parent <gdrive_folder_id>`
3. `python notify.py "<簡報檔>"`
4. `python notify.py --photos "<archive_dir>/YYYY-MM-DD_圖"`
5. 失敗會自動重試並寫入 `執行紀錄.log`；圖片單張失敗不中斷，重跑會自動跳過已送出的

## 護欄
- 不下單、不喊買賣、不給個人化投資建議
- 只用公開來源；付費/需登入的內容不抓
- 結尾「非投資建議」聲明不可省略
